# Мониторинг астенопии глаз при работе за компьютером

Бакалаврская работа (СФУ, ИКИТ, направление 09.03.02 «Информационные
системы и технологии»). Приложение с графическим интерфейсом, которое
через веб-камеру в реальном времени отслеживает моргания пользователя
и признаки покраснения глаз, чтобы выявлять симптомы астенопии
(зрительного утомления) при длительной работе за компьютером.

## Как это работает

- **MediaPipe Face Mesh** находит на кадре с камеры сетку лица и
  координаты точек глаз (`LEFT_EYE` / `RIGHT_EYE`).
- По этим точкам считается **коэффициент моргания** (отношение
  горизонтального и вертикального размеров глаза) — по нему
  определяется закрытие глаза и считаются моргания в единицу времени.
- Отдельный модуль (`red.py`) по HSV-маске оценивает **покраснение
  области глаз** на снимках.
- Результаты и уведомления выводятся в GUI на Tkinter
  (`main2.py` / `build/gui.py`) и всплывающими тостами Windows
  (`win10toast`).

## Структура репозитория

```
main2.py            — точка входа GUI (использует build/utils.py и build/assets)
фото.py             — модуль подсчёта моргания (используется main2.py)
red.py              — определение покраснения глаз по HSV
custombutton.py     — кастомная скруглённая кнопка Tkinter
build/              — «портативная» версия GUI (gui.py, utils.py, assets/,
                       gui.spec для сборки в .exe через PyInstaller)
*.png               — тестовые изображения для red.py
pdf_text.txt        — извлечённый текст пояснительной записки к диплому
requirements.txt    — зависимости проекта
```

`build/` — это отдельный, самодостаточный вариант интерфейса
(сгенерированный UI-билдером и упакованный `gui.spec`-файлом для
PyInstaller): пути к ассетам в нём относительные, в отличие от
`main2.py`, где путь к `build/assets/frame0` захардкожен под исходную
машину разработки.

Из репозитория исключены (см. `.gitignore`): виртуальные окружения,
`__pycache__`, результаты сборки PyInstaller (`build/build`, `build/dist`),
служебные логи запуска и установочный архив зависимостей — всё это
локальные артефакты, не нужные для просмотра исходного кода.

## Установка и запуск

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python main2.py
```

Для сборки автономного .exe из портативной версии интерфейса:

```bash
cd build
pip install -r requirements.txt
pyinstaller gui.spec
```

## Требования

- Python 3.11
- Веб-камера
- Windows (используются `win10toast` и системные пути автозагрузки)
